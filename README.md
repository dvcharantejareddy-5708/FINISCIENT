# FINISCIENT

Phone-first financial intelligence companion (FinTech & Commerce).

**Your money, before it becomes a problem.**


## Run

```bash
npm install
npm run dev
```

Open the local URL on a phone-sized viewport (360–430px). Desktop shows a centred device column.

## Architecture

UI → state → deterministic financial engine → local explanation layer → dataset.

AI never invents amounts. Trust badges: OBSERVED, CALCULATED, PREDICTED, GOAL IMPACT.

The Android Share Target in this web prototype is an interactive simulation, not a native Android intent handler.



## Solution
FINSCIENT transforms spending into:
- Personal baseline insights
- Goal impact analysis
- What-if simulations
- Explainable recommendations

## Features
- CSV transaction import
- Automatic categorization
- Baseline detection
- Goal simulator
- AI explanations
